Build a Quote Comparison Sheet Before the Second Venue Replies

August 21, 2026 · The Retreat Register

The first quote is per person per night. The second is a flat number for the whole property. The third looks cheapest because it quietly leaves meals out.

None of them line up, and choosing between them from memory is guessing with paperwork.

Build the sheet before the second reply lands: one row each for lodging, meals, meeting space, service fees, taxes, deposit, and cancellation terms. When a quote arrives, rewrite it into those rows and mark every blank the venue left.

The blanks are the point. A missing row is a question to send back in writing before any comparison is real.

Quotes are only comparable after someone makes them comparable. One page does it, and the blanks it exposes are worth more than the totals.
